# YearDream 사용자 설명서

**결과 생성 위치: `YearDream.exe`가 있는 폴더의 `result.json`과 `result_extra.json`.** 다운로드 버튼은 브라우저 다운로드 폴더에 별도 사본을 저장합니다. 결과 파일은 성공한 다음 분석에서 갱신되므로 보존할 결과는 다른 폴더에 복사하세요. 여러 분석의 동시 실행은 피하세요.

## 실행

1. Windows 11 x64 PC에서 배포 ZIP을 쓰기 가능한 폴더에 **전체 압축 해제**합니다. ZIP 안에서 바로 실행하거나 exe만 따로 옮기지 않습니다. `_internal` 폴더도 필요합니다.
2. `YearDream.exe`를 실행합니다. Python을 설치할 필요가 없습니다. 서버 콘솔과 기본 브라우저 화면이 열립니다. 화면이 열리지 않으면 콘솔에 표시된 `http://127.0.0.1:8000` 주소에 접속합니다.
3. 분석할 HTTP(S) URL을 입력하고 기본 분석 또는 동적 페이지 분석을 선택한 뒤 ‘탐지 실행’을 누릅니다. 동적 분석은 설치된 Microsoft Edge가 필요합니다. 기본 분석에는 Edge가 필요하지 않습니다.
4. 결과와 경고, 특징·제출 후보·검토 대상 건수를 확인합니다. 필터는 화면만 바꾸며 다운로드 파일은 해당 분석의 전체 결과를 포함합니다.
5. 종료할 때 콘솔 창에서 `Ctrl+C`를 누릅니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

PowerShell에서 실행할 수도 있습니다.

```powershell
.\YearDream.exe
.\YearDream.exe --port 8010
.\YearDream.exe --no-browser --port 8010
```

기본 포트는 8000이고 서버는 이 PC의 127.0.0.1에서만 엽니다. `--port 0`은 사용 가능한 포트를 자동 선택하고 실제 주소를 콘솔에 표시합니다. 네트워크 접근이 가능한 환경에서 대상 웹페이지를 수집하며 GPU·외부 AI API·계정·API 키는 사용하지 않습니다. Edge와 대상 사이트의 외부 리소스에는 네트워크 접근이 발생할 수 있습니다.

## 결과 해석

- `result.json`: HOMOGLYPH·JAMO·TRANSPARENT·OFFSCREEN 특징 중 관련 홍보 원문 구간과 연결된 제출 후보입니다. 규칙이 선택한 항목은 is_violation=true이며 법적 확정 판단을 뜻하지 않습니다.
- `result_extra.json`: 필수 4종과 별도인 도박·성인물 홍보 내용 후보입니다. 일반 표시 광고를 임의의 필수 기법으로 분류하지 않습니다.
- 광고 후보 다운로드: 검수용 위치·문맥·규칙 정보입니다. 후보는 사람이 확인해야 합니다. 특징만 있는 항목은 화면에 검토 대상으로 보존합니다.
- 0건 결과도 빈 findings 배열을 가진 파일로 저장합니다. **0건은 광고 부재를 입증하지 않습니다.** 부분 결과는 수집/시간 제한 경고를 함께 확인합니다.
- 완전한 수집 실패나 분석 완료 전 시간 초과에서는 기존 결과 파일이 남을 수 있습니다. 화면의 성공 여부와 파일의 meta 시각을 확인하여 이전 결과를 새 결과로 오인하지 마세요.

기본값은 문서 최대 8개, 링크 깊이 2, iframe 깊이 3, 공유 시간 예산 60초입니다. 동적 모드는 초기 DOM 로드 뒤 기본 500ms 대기합니다. 자동 스크롤·클릭·로그인·이미지/OCR·Shadow DOM·외부 도메인 프레임 분석은 지원하지 않습니다. 어휘 밖 광고와 문맥·스타일 변형에 오탐·미탐이 남습니다. 공모전의 별도 평가 PC 검증·전체 사이트 정확도 측정은 아직 완료되지 않았습니다.

## 문제 해결

| 증상 | 확인 방법 |
|---|---|
| 실행 직후 종료 | PowerShell에서 exe를 실행해 오류를 확인합니다. 전체 폴더 압축 해제 여부를 확인합니다. |
| Cannot start / 포트 충돌 | 실행 중인 프로그램을 종료하거나 `--port 8010`으로 실행합니다. |
| 쓰기 권한 오류 | Program Files 등 제한된 폴더 대신 사용자가 쓸 수 있는 폴더로 전체 배포 폴더를 옮깁니다. |
| 동적 분석 503 | Microsoft Edge 설치/실행 환경을 확인합니다. 필요하면 기본 분석을 사용합니다. |
| 수집 실패·시간 초과 | 입력 URL·인터넷 연결·사이트 접근 제한과 경고를 확인합니다. |
| 실행 파일 경고/차단 | 이 빌드는 코드 서명되지 않았습니다. 조직 정책에 따라 배포 담당자에게 파일 출처와 검사 결과를 확인합니다. |

이 패키지는 분석 UI/API 실행용입니다. 저장본 수동 검토·평가 CLI는 소스와 Python 환경에서 README 절차로 실행합니다. 이 설명서는 공모전 제출 서류를 대체하지 않습니다.
