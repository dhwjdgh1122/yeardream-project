# 제출 후보 점검표

**실행 위치: `01_run/YearDream/YearDream.exe`. 결과는 같은 폴더의 `result.json`, `result_extra.json`입니다.**

이 문서는 준비 상태 점검용입니다. 서류 작성·서명이나 이메일 제출을 대신하지 않습니다. 최종 확인 전에는 제출 완료로 표시하지 않습니다.

최신 추가 보고: release-20261025-06도 다른 PC에서 정상 작동한다고 사용자가 확인했습니다. 환경·개별 기능 검사 기록은 OTHER_PC_CHECKLIST.md를 따릅니다. 이후 안내 묶음 화면 개선 release-07은 빌드PC 패키지 검사를 통과했고 다른PC 확인은 별도입니다. 아래 소스 ZIP과 제출 폴더 설명은 기존 submission-20261025-02의 준비 상태이며 새 화면을 포함한 제출 묶음은 아직 만들지 않았습니다. 사용자 탐색 화면 집계는 VALIDATION.md에 기록했고 원본 결과·목표 본문 도달 확인은 [실사이트 확인표](SITE_VALIDATION_CHECKLIST.md)를 따릅니다.

공식 근거는 업로드 모집요강 PDF 2·5·8~9·15~18쪽입니다. PDF 기재 접수 마감은 2026-10-23 18:00이며 변경 공지나 실제 접수 여부를 확인한 것은 아닙니다. 이 묶음이 만들어졌다고 접수가 가능한 상태나 접수 완료를 뜻하지 않습니다. `04_forms/original_contest.pdf`가 포함되면 해당 원문 양식도 확인합니다.

AI는 선택사항이며 현재 구현은 외부 AI API·키·서버를 사용하지 않습니다. 동적 분석은 대상 PC에 설치된 Microsoft Edge가 필요합니다. GPU 없이 CPU/RAM에서 분석하는 구조이며 다른 평가 PC에서의 실제 검증은 별도입니다.

현재 제품은 로컬 실행 도구입니다. 신규 플랫폼·사례 검색·RAG 기능은 보류했으며 제출 완료 조건이 아닙니다. DB는 실행 PC의 `%LOCALAPPDATA%\YearDream\history.sqlite3`에 새로 생성되며, 실제 사용자 DB/검토 기록은 배포에 포함하지 않습니다. 현재 PC 직접 사용 점검은 USER_MANUAL.md, 독립 환경 확인은 OTHER_PC_CHECKLIST.md에 실제 수행 결과만 기록합니다.

기존 gen.go.kr 부분 검수에 다른 도메인인 행정안전부의 정상 업무 문구 8블록/16범주 항목 검수를 별도로 추가했습니다. 미검출/보류 항목과 실제 4종 은닉 양성 사례 검증이 남아 전체 광고 탐지 정확도·독립 성능·주최 측 비공개 사이트 통과를 입증하지 않습니다. KISA의 실패/시간 예산 내 미완료 수집은 정상 음성으로 계산하지 않습니다. 검증 수치는 VALIDATION.md와 project.md의 범위·한계를 함께 봅니다. 이 확인은 기존 배포 후보 묶음 생성 이후의 기록입니다.

## 폴더 구성

- START_HERE.md: 실행/결과 위치·미완료 안내.
- 01_run/YearDream: exe와 필요한 전체 파일. 결과 파일은 성공한 분석에서 새로 생성됩니다.
- 02_source/YearDream-source.zip: 소스·설명서·고정 의존성·테스트. 가상환경과 실제 수집 자료는 포함하지 않습니다.
- 03_docs: 현재 사용/빌드 설명서·이 점검표·다른 PC 점검표.
- 04_forms: 별도 작성 서류 안내와 확인된 원문 PDF. 원문 PDF를 작성된 제출 서류로 간주하지 않습니다.
- 05_verification: 빌드 매니페스트와 해당 빌드의 로컬 검사 기록.
- submission-manifest.json: 소스 revision·파일별 SHA-256·분석 코드 일치·남은 항목.

소스에는 exe에서 실행하지 않는 후속 오프라인 검수 도구가 함께 있을 수 있습니다. 변경된 오프라인 파일은 manifest의 offline_source_changes에 따로 기록합니다. 분석 코드·리소스·고정 의존성 등 빌드 입력이 다르면 묶음을 만들지 않으므로 먼저 새 빌드와 검사를 수행합니다.
