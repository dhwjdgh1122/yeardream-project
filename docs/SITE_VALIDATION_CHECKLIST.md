# 메인 URL 탐색·탐지 결과 확인표

실행이 끝난 뒤 화면과 다운로드 결과를 함께 확인합니다. 이 표는 실행 기록 양식이며 미기입 항목을 통과로 취급하지 않습니다. 사용자의 100문서 실행 화면 집계는 VALIDATION.md에 기록했으며 원본 JSON과 목표 게시글 본문 도달 여부는 아직 확인 전입니다.

## 결과 보관

1. 완료 또는 부분 종료 상태, 경과 시간, 실제 탐색·분석 범위를 화면으로 저장합니다.
2. JSON 다운로드·추가 탐지 결과 다운로드·광고 후보 다운로드를 각각 저장합니다. 다음 분석 전에 별도 폴더에 복사해 이전 결과와 구분합니다.
3. ‘수집·분석 문서와 미방문·제외 범위 보기’를 열어 목표 게시글의 방문 상태와 제외 이유를 확인합니다. 필요하면 상세 JSON과 분석 이력의 사본도 확인합니다. 공식 제출 JSON만으로 탐색 범위 전체를 확인할 수는 없습니다.

| 항목 | 실제 결과 |
|---|---|
| 수행 날짜·확인자 / 실행 버전 | 미기록 |
| Windows·Edge 버전 / CPU·RAM | 미기록 |

| 문서 한도 / 링크 깊이 / 시간 예산 | 미기록 |

| 알려진 미방문·제외 URL 수 / 주요 사유 | 미기록 |
| 위장·은닉 특징 / 4종 제출 후보 / 홍보 내용 후보 | 미기록 |
| 결과 파일·화면 보관 위치 | 미기록 |

## 목표 경로 확인

현재 알려진 사례의 시작점은 `https://gen.go.kr/child/main/main.php`, 목표 게시글은 `/child/xboard/board.php`의 `tbnum=6`, `number=107`입니다. 쿼리 순서나 목록 문맥 인자는 달라질 수 있으므로 번호 문자열만 검색하지 말고 해당 게시판과 글인지 함께 확인합니다. `mode1=go` 바로 이동 링크를 발견한 것만으로 실제 본문을 분석했다고 판정하지 않습니다.

| 확인 항목 | 결과·근거 |
|---|---|
| 메인에서 자유게시판 목록에 도달했는가 | 미확인 |
| 107번 게시글의 실제 제목과 본문을 수집했는가 | 미확인 |
| 목표 문서 상태가 탐지 완료인가 | 미확인 |
| 본문 홍보 내용 후보의 문구·위치가 실제 내용과 일치하는가 | 미확인 |
| 미방문이면 깊이·문서·시간 제한 또는 링크 미발견 중 원인이 무엇인가 | 미확인 |
| 수집 성공 후 후보가 없다면 실제 본문 확인과 내용 판별을 구분했는가 | 미확인 |

필요하면 결과를 보관한 뒤 같은 모드로 목표 게시글을 직접 분석해 비교합니다. 메인 경유에서는 미방문인데 직접 분석에서 발견된다면 우선 탐색 범위 문제를 확인합니다. 본문까지 분석했는데 홍보 내용 후보가 없다면 내용 판별과 수집된 본문의 차이를 확인합니다. 두 실행 사이 사이트 내용이 변경될 수도 있습니다.

## 결과 해석

- 수집/분석 건수는 사이트 전체 대비 검사율이 아닙니다. 대기 링크 소진도 로그인·자동 클릭이 필요한 영역 등까지 전수 검사했다는 증거가 아닙니다.
- 알려진 미방문·제외 목록에는 첨부·작업 링크 등이 포함됩니다. 이를 모두 탐지 실패나 사이트 전체 누락 수로 세지 않습니다.
- 목록과 본문에 같은 광고가 반복될 수 있습니다. 후보 수를 고유 광고 수로 보고하려면 게시글 URL과 실제 내용을 대조해 별도로 집계합니다.
- 일반 표시 홍보는 내용 후보에만 포함될 수 있습니다. 필수 4종 제출 후보가 0이어도 내용 후보의 실제 문구를 확인합니다.
- 정상 문구의 오탐과 놓친 광고를 함께 검수한 정답 집합 없이 정확도·재현율·F1을 산출하지 않습니다. 후보 검출은 불법 여부의 확정 판정이 아닙니다.

판정: 미실시 / 목표 경로 도달·본문 탐지 확인 / 부분 완료·누락 원인 확인 / 오류 재현 중에서 실제 근거에 맞게 기록합니다. ‘사이트 전체 탐지 완료’와 구분합니다.
