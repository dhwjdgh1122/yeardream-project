분석 이력·후보 검토 관리

게시판·게시글 링크를 우선 탐색합니다. 100문서는 시험 기준이며 사이트 전체 검사나 25분 내 완료를 보장하지 않습니다.

동적 페이지 분석은 JavaScript로 생성되는 내용과 브라우저에 적용된 숨김 스타일을 확인합니다. 스크롤·클릭이 필요한 내용과 늦게 표시되는 내용은 포함되지 않을 수 있습니다.

대기 중

실행하면 실제 처리 건수와 경과 시간이 표시됩니다. 전체 작업량을 알 수 없어 사이트 검사율은 표시하지 않습니다.

결과 파일과 판정 기준 안내

JSON 다운로드는 4종 위장·은닉 결과, 광고 후보 다운로드는 내용 판별 결과를 저장합니다. 화면 필터와 관계없이 전체 결과를 저장합니다. 광고 후보는 검토가 필요하며 부분 분석 안내도 확인해 주세요.

추가 탐지 결과 다운로드는 광고 후보를 result_extra.json으로 저장합니다. 후보 검출은 불법 여부의 확정 판정이 아닙니다.

4종 제출 결과에는 관련 홍보 표현이 확인된 후보만 포함합니다. 근거가 부족한 특징은 검토 대상으로 화면에 남으며, 정상으로 확정한 결과가 아닙니다.
